# 01 — Execution semantics

Draft, October 5, 2026. Status and scope: [specification index](README.md). This is a restricted simulation contract, not a claim of full SystemVerilog conformance. Implementation must tie each supported SV construct to the selected language edition and a directed fixture.

## Values and initialization

Every value has an explicit width and signedness. Arithmetic wraps to the declared result width; extension, truncation and comparisons follow the normalized CIRCT operation. Shifts at or above the operand width return zero for logical shifts and sign fill for arithmetic right shifts. Host integer overflow, LLVM poison and Rust build mode must not determine results. Division by zero and invalid memory addresses produce explicit domain diagnostics in the supported two-state mode; unsupported language behavior must be diagnosed rather than advertised as full SV equivalence.

MVP circuit arithmetic is two-state. X/Z-dependent operators, resolved multi-driver nets and unsupported unknown conversions are rejected. Async stateful primitives additionally track initialized status; this is not general four-state propagation. Reading required primitive state before reset/initialization fails. Ordinary register/memory initialization is declared per model: explicit value/file or reproducible seeded bits. No implicit host-memory contents are observable.

Initialization order is: allocate and validate storage; apply declared state initialization and initial port values; arm processes and clocks; settle time zero. Required undriven inputs fail validation. Async reset acts during time-zero settling according to the primitive contract. Initialization does not manufacture a clock edge unless a declared clock transition actually occurs.

## Time and event ordering

The initial time base is integer femtoseconds, restricted to nonnegative signed 64-bit range for the Arc boundary. Delay conversion must be exact; nonrepresentable values and overflow fail. No floating-point time or silent rounding is allowed. Report `TimePoint { ticks, delta, phase }`; delta is a checked unsigned counter. “No next event” is an optional value, not a sentinel timestamp.

One coordinator owns each session. At a physical timestamp it executes a restricted iterative scheduling cycle:

1. Publish due driver updates and awaken sensitive processes in the active region. Execute active work to exhaustion, honoring each process's statement order and declared effects.
2. Promote pending inactive work from supported `#0` suspension; drain active work again. Repeat until no inactive work remains.
3. Apply the current ordered batch of nonblocking assignments. Their right-hand values were captured when scheduled. Resulting signal changes may awaken active work; return to step 1 before taking a later NBA batch.
4. When design work is quiescent, service eligible read/write harness callbacks. Any permitted drives restart settling. Deliver read-only callbacks only after all current-time work is quiescent.
5. Advance to the next physical event only after current-time work and callbacks finish.

Delta increments when scheduler work re-enters active processing after a deferred batch or callback round, not on every assignment. Every event also has a stable sequence identity. Deterministic tie-breaking uses semantic process/driver IDs and local event sequence, never addresses or host thread order. This makes legal deterministic cases reproducible; it does not repair a racy SV program. The supported subset rejects conflicting same-round writes from unordered processes; races outside statically checked cases require runtime diagnostics. Full SV scheduling regions and arbitrary testbench races are outside MVP.

## Clocked state and memory

Each edge-sensitive element names its clock, edge and reset priority. Synchronous reset is sampled on its eligible edge; asynchronous reset responds without a clock. Independent clocks, negedges, generated clocks and paused clocks use ordinary events.

For normalized register updates triggered together, sample the state visible at the triggering boundary before committing that batch. Two registers exchanging values at coincident edges must swap correctly. An edge generated by an earlier commit is a later scheduling event and sees the state then visible; there is no single old-state snapshot for an entire physical timestamp. Behavioral blocking assignments retain their process semantics.

Pausing a managed clock cancels future generated transitions using a generation token. Delivered edges remain delivered. Resume specifies a future next-edge time and polarity; it does not emit a catch-up burst. Reset works while paused. Managed clock period/high/low durations must be positive and representable.

Memory descriptors declare dimensions, port clocks, read/write latency, masks, initialization and collision policy. MVP supports single-writer memories and explicitly declared old-data or new-data read-during-write behavior. Competing same-address writes are rejected unless a separately qualified policy exists. An out-of-range access never aliases valid storage.

## Delays, feedback and progress

A queued assignment contains the value captured at scheduling time, destination, delivery time, phase and cancellation identity. Delivery does not reread its source expression. Transport delay preserves every scheduled transition; inertial filtering is confined to primitives with an explicit cancellation rule. Process wait registrations carry generation tokens so an obsolete timeout cannot wake a later wait.

Pure combinational acyclic regions may evaluate in topological order. Stateful feedback is represented by explicit primitives or supported processes. SCC detection diagnoses cycles; it does not justify choosing an arbitrary fixed point for a C-element, latch or oscillator. Unrecognized combinational loops are rejected initially. Supported zero-time feedback has a finite work budget and reports nonconvergence with causal context; a positive-delay oscillator remains a valid timed process.

Quiescence means no runnable current-time work. It is not proof of completion or deadlock. A channel stall becomes a failure only under a declared obligation/deadline or a proven closed wait cycle; external input may legitimately be absent.

## API observation boundaries

| Operation | Required behavior |
| --- | --- |
| `settle` | Drain current-time work only; return settled or an explicit stop/error |
| `run_until(T)` | Process all events at or before T and settle T, then return; if idle, advance physical time to T; reject T earlier than current time |
| `next_event` | Query the earliest live future event; distinguish none from an interior phase that must first resume |
| `drive` | At a settled boundary, stage an input update for current-time processing; supported future drives are explicit scheduled events |
| `read` | Copy values only at a settled/read-only boundary; reject an interior paused phase |
| Budget stop | Pause after an atomic work item, report actual phase and unsettled status; resume without replaying completed effects |

Callback registration specifies phase and whether drives are permitted. Read-only callbacks cannot mutate or recursively step the session. Instrumentation must not change scheduling or random choices. Early `$finish`, failure, cancellation or a budget limit returns its actual frontier, not a fabricated successful `run_until` result.

## Fast-path obligations and tests

Full-scan mode executes all eligible pure regions while preserving trigger conditions and exactly-once side effects. Tracked mode must produce the same observations. Consume activation before evaluation or use generations so reactivation survives. Always-run regions must still notify tracked consumers. Delay events, commits, callbacks and stateful models cannot be duplicated by partition replication.

A clocked fast path may skip queue machinery only when it preserves all observable edges, phases, resets and external interactions. Async regions retain exact events. Future CPU threading or GPU execution must yield at the same required boundaries.

Acceptance: SEM-01–06, OPT-01–02 and ASY-03. Required traces include register swap, NBA re-entry, `#0`, captured delayed payload, canceled wakeup, reset during pause, time overflow, interior budget resume, and inclusive `run_until`. Compare tiny hand-authored expected traces with an independent evaluator before relying on optimized-versus-unoptimized comparisons.
